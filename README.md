# ひとこと診断

「今日のあなた、多分きっとこんな日。かも。」
今日も気をぴっちり張って頑張っている、あなたのために。
フッと力が抜けるような、心がゆるむような、そんなひとことを届ける診断アプリです。
診断結果はランダムで表示され、一部には低確率のレアメッセージも含まれています。

## URL

https://one-word-diagnosis.onrender.com

---

## アプリ概要

ボタンを押すだけで、ランダムな「ひとこと診断」が表示されるシンプルなWebアプリです。
「少しクスッとできる」「ゆるく楽しめる」体験を目指して制作しました。
また、診断結果をXへシェアできる機能も実装しています。

---

## 開発背景

初めての個人開発として、

* Dockerを用いた開発環境構築
* MySQLからPostgreSQLへの移行
* Render / Neon を利用したデプロイ
* Railsでの画面遷移やDB連携

などを実践しながら、「公開まで持っていくこと」を目標に制作しました。

特に、開発中には

* Dockerが別ディレクトリを参照していた問題
* db:seedで重複データ増殖問題
* 本番環境でのDB接続エラー

など、初学者ならではのトラブルにも多く直面しました。

その都度原因を切り分けながら解決したことで、
「コードを書く」だけでなく、「環境を理解すること」の大切さを学びました。

## こだわったポイント

### 世界観の統一感

シンプルなアプリだからこそ、
「空気感」や「温度感」の統一を特に意識しました。

* フォント
* 色味
* UIデザイン
* 診断結果の文章

まで含め、全体をゆるく柔らかい雰囲気に寄せています。

---

### 「断定しない診断」

診断アプリ特有の断定口調ではなく、
「ゆるっとした ひとことをもらう」
くらいの軽さを意識しました。

そのため、診断結果自体も
少しクスッとできたり、力が抜けるような言葉選びを意識しています。

---

### レア要素

診断結果には、低確率で「雑学」が表示されます。

また、診断結果がレアの場合、
レアバッジの表示と金色にキラキラ光っているようなの文字色にすることで、
通常結果とレア結果の差を内容だけでなく視覚的にも分かりやすく楽しめるように工夫しています。

「次はレアが出るかも」と、ついもう一回押したくなる体験を目指しました。

また、雑学そのものがもともと自分の好きな要素でもあり、
アプリに自分らしさを入れられたポイントでもあります。

---

### 手軽に何度も遊べる導線

* 診断する
* 診断中…
* 結果表示
* トップへ戻る
* シェアする

までをシンプルな導線にすることで、テンポよく何周も遊べるよう意識しました。
